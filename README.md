## 🤖 Chapter 2 — Supervised Learning

> **Supervised Learning** merupakan metode Machine Learning yang menggunakan data yang memiliki **label atau target**.

### 📌 Materi yang Dipelajari

- Classification and Regression
- Generalization, Overfitting, and Underfitting
- Relation of Model Complexity to Dataset Size
- k-Nearest Neighbors
- Linear Models
- Naive Bayes Classifiers
- Decision Trees
- Ensembles of Decision Trees
- Kernelized Support Vector Machines
- Neural Networks
- Uncertainty Estimates from Classifiers

💡 Melalui praktik ini, saya menjalankan kode dari setiap materi untuk memahami penerapan algoritma **Supervised Learning** dalam melakukan klasifikasi maupun prediksi.

## 🔍 Chapter 3 — Unsupervised Learning and Preprocessing

> **Unsupervised Learning** merupakan metode Machine Learning yang digunakan untuk menemukan pola atau struktur pada data yang tidak memiliki label.

### 📌 Materi yang Dipelajari

- Types of Unsupervised Learning
- Challenges in Unsupervised Learning
- Preprocessing and Scaling
- Data Transformations
- Dimensionality Reduction
- Principal Component Analysis (PCA)
- Non-Negative Matrix Factorization (NMF)
- Manifold Learning with t-SNE
- k-Means Clustering
- Agglomerative Clustering
- DBSCAN
- Comparing and Evaluating Clustering Algorithms

💡 Pada chapter ini, kode dijalankan untuk memahami proses **preprocessing**, reduksi dimensi, serta pengelompokan data menggunakan beberapa metode **clustering**.
