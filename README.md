Tugas Machine Learning – Supervised dan Unsupervised

Deskripsi:
Tugas ini merupakan praktik mata kuliah Machine Learning dengan menjalankan kode yang terdapat pada buku Introduction to Machine Learning with Python, khususnya Chapter 2: Supervised Learning dan Chapter 3: Unsupervised Learning and Preprocessing. Kode dijalankan menggunakan Python melalui Google Colab untuk memahami konsep, cara kerja algoritma, serta hasil yang diperoleh dari setiap metode.

Chapter 2 – Supervised Learning:
Chapter 2 membahas Supervised Learning, yaitu metode Machine Learning yang menggunakan data yang memiliki label atau target. Materi yang dipelajari dan dipraktikkan meliputi:
- Classification and Regression
- Generalization, Overfitting, and Underfitting
- Relation of Model Complexity to Dataset Size
- k-Nearest Neighbors
- Linear Models
- Naive Bayes Classifiers
- Decision Trees
- Ensembles of Decision Trees
- Kernelized Support Vector Machines
- Neural Networks
- Uncertainty Estimates from Classifiers
Melalui praktik ini, saya menjalankan kode dari setiap materi untuk memahami penerapan algoritma Supervised Learning dalam melakukan klasifikasi maupun prediksi.

Chapter 3 – Unsupervised Learning and Preprocessing:
Chapter 3 membahas Unsupervised Learning dan preprocessing data. Unsupervised Learning digunakan untuk menemukan pola atau struktur pada data yang tidak memiliki label.
Materi yang dipelajari dan dipraktikkan meliputi:
- Types of Unsupervised Learning
- Challenges in Unsupervised Learning
- Preprocessing and Scaling
- Data Transformations
- Dimensionality Reduction
- Principal Component Analysis (PCA)
- Non-Negative Matrix Factorization (NMF)
- Manifold Learning with t-SNE
- k-Means Clustering
- Agglomerative Clustering
- DBSCAN
- Comparing and Evaluating Clustering Algorithms
Pada chapter ini, kode dijalankan untuk memahami proses preprocessing, reduksi dimensi, serta pengelompokan data menggunakan beberapa metode clustering.

Tujuan:
Tugas ini bertujuan untuk memahami konsep dan penerapan Supervised Learning serta Unsupervised Learning, sekaligus mengetahui cara kerja berbagai algoritma Machine Learning melalui praktik langsung menggunakan kode dari buku.

Tools:
- Python
- Google Colab
- NumPy
- Pandas
- Scikit-learn
- Matplotlib

Kesimpulan:
Melalui tugas ini, saya dapat memahami perbedaan antara Supervised Learning yang menggunakan data berlabel dan Unsupervised Learning yang bekerja dengan data tanpa label. Selain itu, praktik ini memberikan pemahaman mengenai preprocessing, reduksi dimensi, klasifikasi, regresi, dan clustering dalam penerapan Machine Learning.
